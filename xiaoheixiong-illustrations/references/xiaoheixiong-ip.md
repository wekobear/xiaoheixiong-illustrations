# 小黑熊 IP

## 角色定义

小黑熊是本 skill 中文正文配图的固定视觉 IP。

默认每张图都要出现小黑熊。小黑熊不是吉祥物，不是贴纸，不是可爱装饰，而是正在认真参与系统运转的荒诞工作者。

## 外形

- 黑色实心小熊，头顶两只圆耳朵。
- 白色圆点眼睛，可以有极简的口鼻短线。
- 细胳膊，细腿。
- 脖子上有一条小小的橙色针织围巾，是小黑熊唯一的固定彩色识别物。
- 身体可以是圆柱、黑豆、黑盒、影子、洞口、机器内部黑块。
- 轮廓略微不规则，有手绘抖动感。
- 表情空、呆、冷静、认真。

参考图（外形拿不准时按此校准，默认使用橙围巾）：

- `assets/character-sheet.png`：官方形象设定图，主姿态 + 三个动作姿态（橙围巾）。
- `assets/turnaround-orange-scarf.png`：橙围巾三视图（正面 / 侧面 / 背面），含围巾结与背面耳位。
- `assets/turnaround-blue-scarf.png`：蓝围巾变体三视图，四肢略粗壮，是该变体的对齐基准。

蓝围巾是可选变体，只在用户明确要求蓝色版本时使用；默认生成一律橙围巾。当小黑熊变成影子、漏斗、洞口等非人形态时，可省略围巾，但圆耳朵尽量保留。

## 性格

- 很认真，但做的事有点荒诞。
- 像一个低调的系统操作员。
- 冷幽默，不卖萌。
- 有点笨拙，但不蠢。
- 像在白板草图里真的负责某个工作。

## 表情库

默认空表情，但不要求每张图都一模一样地呆。允许表情随画面情绪微变，只要不破坏 deadpan 气质。示例参考图：`assets/expressions-library.png`。

| 表情 | 画法（眼睛 / 嘴） |
|---|---|
| 空白（默认） | 两个白点眼 / 一条短横线嘴 |
| 专注 | 白点眼略大 / 嘴抿成更短的横线 |
| 疑问 | 一只眼略高略小 / 嘴画成小斜线 |
| 使劲 | 眼画成两条下弯闭眼弧 / 嘴下竖两三根小短线 |
| 冒汗 | 默认脸 + 太阳穴一滴蓝色小汗珠 |
| 叹气 | 眼画成两条短横杠 / 嘴画成小圆 o |
| 呆住 | 眼画成两个小空心圆圈 / 嘴拉长成平线 |
| 得意 | 眼画成两条上弯弧线 / 嘴一端微微上挑 |
| 累 | 眼皮半垂短横杠 / 嘴画成微微下弯的波浪短线 |

表情规则：

- 眼睛只允许四种元素：白点、短横杠、小空心圆、短弧线。
- 嘴只是一条短线或小圆 o。不要露齿笑，不要张大嘴。
- 不要闪光眼、泪眼汪汪、腮红、脸红特效等萌系元素。
- 一张图通常只用一种表情；前后对比图最多两种。
- 表情服务于叙事（卡住、费力、看坑、等待），不要为了可爱而加。

## 常见职责

让小黑熊承担核心动作：

- 搬运素材。
- 拉线汇聚信息源。
- 卡在断点里。
- 在机器里操作“判断”杆。
- 变成筛选漏斗。
- 切开“素材鱼”。
- 盖章承接话术。
- 牵着承接路径。
- 举警告牌看坑。
- 从洞里伸手但接不住内容。
- 在旁边搬砖、搭桥、开门、分拣、记录。

## 禁止

- 不要把小黑熊画成过度可爱的吉祥物。
- 不要画成儿童卡通角色。
- 不要给小黑熊复杂服装、表情包、闪亮眼睛。
- 不要给小黑熊加围巾以外的其他配饰，也不要把围巾画大、画飘。
- 不要让小黑熊只是站在角落里看。
- 不要让小黑熊抢走结构表达。
- 不要把小黑熊画得太商业、太圆润、太精致。

## 判断标准

如果去掉小黑熊，图的核心隐喻还能完全成立，说明小黑熊太装饰了；要重写提示词，让小黑熊成为动作主体。
